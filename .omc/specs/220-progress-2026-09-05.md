`--mode json` (the mode the print channel actually spawns): identical shape — `SIGTERM -> exit in 0.139s,
returncode=1`, `sleep 120` gone within 1 s, 7343 bytes of JSONL on stdout, the same two tracebacks on stderr
(`scratchpad/live_stderr_json.txt`).

Three facts, measured:

1. **The cooperative path WORKS for what matters**: `dispose()` ran ("Request aborted"), the bash-tool
   grandchild `sleep 120` (a `setsid` session leader — `tools/bash.py`) was gone within 1 s, and the child
   was gone in 0.172 s. This is ADR-0197's claim and it holds.
2. **The exit code is 1, not 143, and stderr carries two tracebacks.** `_signal_cleanup_and_exit` calls
   `sys.exit(128 + sig)` INSIDE A TASK. `SystemExit` propagates out of the loop mid-step; `asyncio.run`'s
   `Runner.close()` then fails with `RuntimeError: Event loop stopped before Future completed`, which
   REPLACES the `SystemExit` ("During handling of the above exception…"), `main_sync` re-raises it, and
   the interpreter exits 1 with a traceback. Plus a "Task exception was never retrieved" for the cleanup
   task. Pi's `process.exit(143)` (`print-mode.ts:60`, origin/main 47236c8) has no loop to tear down; the
   literal port is wrong in Python.
3. **Consequence for #220's Windows measurement**: `SIGBREAK` will take exactly this path for the first
   time on the windows leg, and `TerminateJobObject(job, 1)` ALSO reads as exit 1 (#202 handoff §3-12).
   With the code as it stands the two are indistinguishable except by stderr tail. So the print-mode
   exit path must return the code (`128 + sig`) through `run_print_mode` → `_async_main` → `main_sync`
   instead of raising `SystemExit` in a task — and the spec's "assert 143 / 149" only becomes true after
   that change. Draft spec §A.3/§D.4 assumed 143 was already the observable; it was not. Fed into
   revision 2.

Also observed: text mode's step 7 prints "Request aborted" and sets `exit_code = 1` for the aborted
`stop_reason` — so even with the `SystemExit` fixed, a signal-driven exit must override that 1 with
`128 + sig`, or the parent cannot tell "killed by us" from "the model errored".
