## 5. Deviations from the design, and why

1. **A seventh stale-claim site, corrected.** §D.0 named six. A widened grep found
   `tests/tui/test_completion.py:883` carrying the same "only the walk spends that budget"
   claim in a comment. It is outside §F's grep, but §D.0's own rule ("an implementer who only
   appends has not done §D") applies, so it was qualified in the same edit.
2. **⑩ does not kill a memoizing getter; ⑦ does.** The critique table records "measured, both
   [memoizing and `async def`] fail case ⑩ as written". Re-measured here: the `async def`
   mutation does fail ⑩, the memoizing one does **not** — every ⑩ case reads the getter at
   most once after its last write, so a cache is invisible to them. It is killed by ⑦, which
   reads "on", toggles, and re-reads "off". Mutation coverage is unchanged; the attribution in
   the design's table is wrong for that one row.
3. **Numbers.** Everything in §0/§3 and in the CHANGELOG / ADR / decisions-README prose is
   from `impl/recount.py` and `impl/budget.py` in this lane. Three numbers are **carried from
   the design, not re-taken here** and are labelled as measurements of the same fixture shape:
   the ADR `Corrected` note's "20000/20000 vs 14" and "1556 of 20000 kept paths differed", and
   the `2.05 s` stale-TTL figure in the code comments and the ADR.
4. **Case count.** §C names 16 cases; they land as **24** test functions (⑩ is a six-case file
   shaped on `test_features_agents_flag.py`, and ⑭ carries the design's toggle-ON mirror as its
   own function so a failure names which arm broke). *Corrected in §8:* this said 23, and it was
   22 before the pre-merge fix pass added ②b and ⑭b. Re-measured per file against `7fa6796` —
   `grep -cE '^\s*(async )?def test_'` now vs base: test_completion.py 71/64, test_settings_rows.py
   29/26, test_completer_wiring.py 6/0, test_respect_gitignore_flag.py 7/0, test_settings_types.py
   8/7 → **+24**. The earlier 23 was never re-derived; this one is.
5. **`SettingsRow.live` wording.** ⑯ asserts the literal string `ONE OF TWO`, so the field doc
   is wrapped exactly as the design drafted it (the phrase must not break across lines).
