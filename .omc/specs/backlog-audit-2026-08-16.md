## 3. 작업 계획

### 스프린트 0 — 오너만 할 수 있는 것 (30분)

**12건이 작업이 아니라 미답 질문**이라 목록에서 작업과 구분되지 않는다. 한자리에서 답하거나
닫으면 백로그가 71 → 59로 줄고, 그중 셋은 아래를 막고 있다.

| 질문 | 막는 것 |
|---|---|
| **#138** 세션 JSONL 리댁션 정책 | 스프린트 1 |
| **#128** capability 게이트 하드닝 범위 | 스프린트 2 |
| **#61** 프로바이더 라이브 스모크 (실제 키) | 스프린트 4 |
| #43 #45 #42 #48 #30 #47 #86 #157 #171 | 각자 |

**#29를 쪼갤 것.** XL로 보이는 건 다섯 이슈가 한 벌 안에 있어서다. MCP 게이팅 구멍만 떼면
**보안 M**, 나머지(영속화 + `AgentTool.mutates`)가 별건. 이미 배포된 셋(승인 패널 · tree-sitter
· tool-hiding)은 삭제 — 정정 블록이 이미 그렇게 적어뒀다.

### 스프린트 1 — 세션 데이터 안전 `#137 → #138 → #139`

백로그 **유일한 재현 가능 데이터 손실**. 터미널 두 개로 한 세션(`aelix --continue`가 같은
파일을 잡음)이면 턴 하나가 **에러 없이** 사라진다. #138은 에이전트가 읽은 모든 `.env`·자격증명이
`~/.aelix`에 평문으로 남아 백업·export로 나간다. #139는 그 더미가 무한히 자란다.

셋 다 **코드보다 결정이 먼저**라 미루면 썩는다. #137은 flock이 답이 아니고(이슈 제목이 명시)
프로세스 로컬 상태가 원인.

### 스프린트 2 — 권한 게이트 `#29-split → #127 → #128`

**실측 확인함**: `permission._MUTATING`은 고정 이름 8개
(`bash edit write sh shell create_file execute_command write_file`)이고 MCP 도구는
`{server}__{tool}`로 등록된다(`mcp/adapter.py:85`). `permission.py:503`의
`if not is_mutating: return None` — **파일 쓰는 MCP 도구가 승인창을 아예 안 거친다.**
PLAN 모드도 같은 플래그를 쓰므로 못 잡는다(`:497`).

#127/#128은 실제 결함이지만 **공격자가 이미 in-process 코드 실행을 가진 상태**를 전제 — 뒤에.

### 스프린트 3 — 멈춤 `#146 → #130 → #147` (+ #6 잔여)

셋 다 S인데 결과가 최악: 결과도 에러도 종료도 없음.
- `--mode rpc < /dev/null` **영구 정지** — 감독 스크립트가 쓰는 바로 그 모양
- stdio MCP 서버 하나가 `list_tools()` 중 죽으면 **다른 서버 도구까지 전부** 날아감
- #147은 ADR-0225 이후 남은 절반

**#6의 살아있는 잔여를 여기 붙일 것**: MCP 도구에 우리가 정한 타임아웃이 **하나도 없다**
(`read_timeout_seconds=None` → SDK가 `anyio.fail_after(None)`). TUI는 Esc로 빠지지만
`--print`/rpc는 탈출 불가. 같은 "영원히 멈춤" 계열.

### 스프린트 4 — 작동하지 않는 컨트롤 `#84 #41+#58 #148`

`/settings`에서 스위치 11개를 넘겨도 아무 일도 안 일어난다. 개별로는 S인데 신뢰를 가장 빨리
잃는 종류. **#41을 #58로 접을 것** — "테마가 저장되지만 적용되지 않는다" 한 이슈로. 감지
(OSC 11)는 내장 표면이 `Theme`을 소비하기 전엔 무가치.

### 스프린트 5 — Windows `#103` 먼저

`#103`만 먼저. 몇 시간이면 되고 **PyPI 메타데이터에서 거짓 주장을 제거**한다 — 네 pyproject가
전부 `OS Independent`를 선언하는데 win32에서 테스트도 CI도 돈 적이 없다. windows-latest 잡
없이는 나머지 7건이 전부 추측.

**Windows 8건(#110 우산)은 그대로 둘 것** — 흩어진 게 아니라 제대로 쪼개진 것이다.
