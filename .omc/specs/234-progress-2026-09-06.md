## 5. Deviations from the design, and why

1. **`docs/decisions/README.md` is in the change and §D/§F do not name it.** The ADR index row for
   0238 records each amendment's landing (#220, #221, #222) in its summary; leaving it at #222 would
   make the repo's "authoritative source of design decisions" stale against the ADR it indexes
   (CLAUDE.md rule 2). One sentence added, in the row's own Korean voice, carrying the same numbers.
   Drop it if the orchestrator prefers §F's file list literally.
2. **C.2 arm 2 needed three references dropped before the collection to discriminate at all.** As
   first written it did not kill mutation 4 (`265 passed`): the cancelled exec task keeps `exec`'s
   frame reachable through its `_cancelled_exc` traceback, the frame keeps `watcher_task`, and the
   hook keeps the exec task — so `gc.collect()` reached nothing and the arm asserted a silence it had
   not measured. `second.exec_task = None; del task, _done, pending` before `_settle_the_gc()` fixes
   it, and the mutation then dies on exactly the assert the design assigns to it. This is a
   strengthening of the case, not a change of its subject; arm 1 needed no such drop (its `exec`
   returns normally, so the frame is released) and it kills mutation 3 as designed.
3. **The citation `--fix` relocated three lines, not the two §H row 14 predicts.** The third is
   `test_abort_signal.py:120-129` → `127-136`, cited from `test_bash_tool_containment.py`: §C's own
   code needs four new imports and the module docstring gains two lines, which the design's line
   arithmetic did not account for. The file was already in the commit, so the commit's file list is
   unchanged. Comment text only.
4. **C.1's arms are `pytest.param(..., id=…)` rather than a bare tuple list**, so the id says which
   arm reddened (`normal-leg-inline-cancel`, `timeout-leg-inline-cancel`,
   `normal-leg-call_soon-cancel`), as §C requires.
5. Mutations 2 and 5 kill more cases than the design's table predicts. Nothing was adjusted to match
   the table; the measured result is in §3.
